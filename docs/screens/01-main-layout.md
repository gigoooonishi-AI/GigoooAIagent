## 2. サイドバー

### 2.1 構成要素

| # | コンポーネント | 説明 |
|---|--------------|------|
| 1 | 新規チャットボタン | 現在のエージェントで新しいチャットを開始 |
| 2 | エージェントカード | エージェント選択・展開表示 |
| 3 | プロジェクトフォルダ | チャットをグループ化 |
| 4 | チャット履歴 | 過去のチャット一覧（最大50件） |
| 5 | ダッシュボードボタン | 営業ダッシュボードを開く |
| 6 | ステータス表示 | WebSocket接続状態・メッセージ数 |

### 2.2 エージェントカード

```
┌─────────────────────────────────────────────┐
│ 🔍 社内スキル検索                    active │
│    スキルシート参照                          │
└─────────────────────────────────────────────┘

状態:
- active: 選択中（背景色変更）
- idle: 未選択
- thinking: AI処理中
```

### 2.3 プロジェクト・履歴

```
┌─────────────────────────────────────────────┐
│ 🔍 社内スキル検索                    active │
├─────────────────────────────────────────────┤
│   [📁 新しいプロジェクト]                   │
│                                             │
│   📂 プロジェクトA                    (3)   │
│   │  ├─ ⋮⋮ チャット1           1/10  ─     │
│   │  ├─ ⋮⋮ チャット2           1/08  ─     │
│   │  └─ ⋮⋮ チャット3           1/05  ─     │
│                                             │
│   📁 プロジェクトB                    (1)   │
│                                             │
│   ─────────────────────────────────────     │
│   整理されていないチャット                   │
│   ├─ ⋮⋮ チャット4  📁▼       1/15  ─       │
│   └─ ⋮⋮ チャット5  📁▼       1/12  ─       │
└─────────────────────────────────────────────┘

凡例:
⋮⋮  = ドラッグハンドル（D&D対応）
📁▼ = プロジェクト移動ドロップダウン
─   = 削除ボタン
(3) = プロジェクト内チャット数
```

### 2.4 操作

| 操作 | アクション |
|-----|----------|
| エージェントクリック | エージェント選択 + 展開 |
| プロジェクト作成 | 「📁 新しいプロジェクト」クリック |
| プロジェクト展開/折りたたみ | プロジェクトヘッダークリック |
| チャット読み込み | チャット項目クリック |
| チャット移動 | ドラッグ&ドロップ or ドロップダウン |
| チャット削除 | 「-」ボタン → 確認モーダル |
| プロジェクト名変更 | 「✏️」ボタン |

### 3.2 ヘッダー

| 要素 | 説明 |
|-----|------|
| アイコン | エージェントのアイコン |
| 名前 | エージェント名 |

### 3.3 メッセージエリア

- スクロール可能
- 新しいメッセージで自動スクロール
- Markdownレンダリング対応

### 3.4 入力エリア

| 要素 | 説明 |
|-----|------|
| テキストエリア | メッセージ入力（複数行対応） |
| 📎 ボタン | ファイル添付 |
| ➤ ボタン | 送信（Enter でも送信可） |

### 3.5 対応ファイル形式

| 種類 | 拡張子 |
|-----|-------|
| 画像 | PNG, JPG, GIF, WEBP |
| ドキュメント | XLSX, XLS, DOCX, DOC, CSV |
