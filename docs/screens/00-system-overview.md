# システム概要

## 1. アプリケーション概要

GIGOOO AIエージェントは、営業活動を支援するAIエージェントシステムです。
7つの専門AIエージェントと営業ダッシュボードで構成されています。

## 3. 技術スタック

### フロントエンド

| 技術 | バージョン | 用途 |
|-----|----------|------|
| React | 18.x | UIフレームワーク |
| TypeScript | 5.x | 型安全な開発 |
| Vite | 5.x | ビルドツール |
| CSS | - | スタイリング |

### バックエンド

| 技術 | バージョン | 用途 |
|-----|----------|------|
| Python | 3.14 | 言語 |
| FastAPI | 0.x | Webフレームワーク |
| SQLAlchemy | 2.x | ORM |
| SQLite | - | データベース |
| OpenAI API | - | AI機能 |

### 通信

| 方式 | 用途 |
|-----|------|
| REST API | CRUD操作、データ取得 |
| WebSocket | チャットストリーミング |
