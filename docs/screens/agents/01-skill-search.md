## 3. 機能一覧

| 機能 | 説明 |
|-----|------|
| スキル検索 | キーワードでスキルシートを検索 |
| 人材マッチング | プロジェクト要件に合う人材を提案 |
| スキル詳細表示 | 社員のスキル詳細を表示 |
| 複合検索 | 複数スキルの組み合わせ検索 |

## 4. 入力例

| 入力 | 期待される応答 |
|-----|--------------|
| `Pythonが得意な人` | Python経験者の一覧 |
| `React + TypeScriptができる人` | 両方のスキルを持つ人 |
| `AWS資格を持っている人` | AWS認定資格保持者 |
| `新規プロジェクトに5名アサインしたい。必要スキルは...` | 要件に合う人材を提案 |

## 8. RAG設定

- **データソース**: スキルシートDB（ベクトル化済み）
- **検索方式**: セマンティック検索
- **上位件数**: 10件
