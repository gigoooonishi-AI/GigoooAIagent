# 問い合わせ対応 (inquiry)

## 1. 概要

| 項目 | 内容 |
|-----|------|
| エージェントID | `inquiry` |
| 名前 | 問い合わせ対応 |
| アイコン | 💬 |
| 説明 | 顧客からの問い合わせに対する回答案を自動作成 |

## 3. 機能一覧

| 機能 | 説明 |
|-----|------|
| 回答案生成 | 問い合わせに対する回答案を自動生成 |
| テンプレート活用 | FAQ・過去回答を参照 |
| トーン調整 | フォーマル/カジュアルの調整 |
| 多言語対応 | 英語等への翻訳 |
| 回答コピー | 生成した回答をクリップボードにコピー |

## 4. 入力例

| 入力 | 期待される応答 |
|-----|--------------|
| `料金プランについて教えてという問い合わせへの回答` | 料金プランの説明を含む回答案 |
| `導入期間はどれくらいかという質問への回答` | 導入期間・スケジュールの説明 |
| `競合との違いを聞かれた場合の回答` | 自社の強み・差別化ポイント |
| `クレーム対応の回答を作成して` | 丁寧な謝罪と対応策 |

## 5. 出力フォーマット

### 回答案

```markdown
**📧 回答案**

---

{顧客名} 様

{挨拶文}

{本文}

{締めの挨拶}

---

[📋 コピー] [✏️ 編集]
```

### トーン別出力

**フォーマル:**
```
お問い合わせいただき、誠にありがとうございます。
弊社製品についてご案内申し上げます。
```

**カジュアル:**
```
お問い合わせありがとうございます！
製品についてご説明しますね。
```

## 6. API連携

| エンドポイント | Method | 説明 |
|--------------|--------|------|
| `/api/chat` | POST | チャットAPI |
| `/api/sales/inquiries` | GET | 問い合わせ一覧 |
| `/api/sales/inquiries/{id}` | GET | 問い合わせ詳細 |
| `/api/sales/inquiries/{id}/generate-response` | POST | 回答生成 |

## 7. システムプロンプト

```
問い合わせ対応エージェントです。顧客からの質問に対する回答案を作成します。
```

## 8. 回答生成パラメータ

| パラメータ | 説明 | デフォルト |
|-----------|------|----------|
| tone | トーン（formal/casual） | formal |
| length | 長さ（short/medium/long） | medium |
| include_signature | 署名を含めるか | true |
| language | 言語 | ja |
