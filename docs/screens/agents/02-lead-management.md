| 項目 | 内容 |

## 3. 機能一覧

| 機能 | 説明 |
|-----|------|
| リード分析 | BANT分析、スコアリング |
| 優先度判定 | Hot/Warm/Coldの判定 |
| アクション提案 | 次のアクションを提案 |
| 失注理由分析 | 失注案件の分析・改善点 |
| リスク評価 | 案件のリスク要因を特定 |

## 4. 入力例

| 入力 | 期待される応答 |
|-----|--------------|
| `株式会社ABCのリードを分析して` | BANT分析、スコア、推奨アクション |
| `今週フォローすべきリードは？` | 優先度の高いリード一覧 |
| `失注した案件の傾向を教えて` | 失注理由の分析レポート |
| `HOTリードの一覧を見せて` | HOT判定のリード一覧 |

## 6. API連携

| エンドポイント | Method | 説明 |
|--------------|--------|------|
| `/api/chat` | POST | チャットAPI |
| `/api/sales/leads` | GET | リード一覧 |
| `/api/sales/leads/{id}` | GET | リード詳細 |
| `/api/sales/leads/{id}/analyze` | POST | AI分析 |

## 8. 温度判定基準

| 温度 | スコア | 条件 |
|-----|-------|------|
| 🔥 HOT | 80-100 | 予算・決裁者・時期が明確 |
| 🟡 WARM | 50-79 | 一部条件が不明確 |
| 🔵 COLD | 0-49 | 情報収集段階 |
