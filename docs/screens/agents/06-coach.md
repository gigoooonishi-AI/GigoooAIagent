## 3. 機能一覧

| 機能 | 説明 |
|-----|------|
| 商談分析 | 議事録・録音の分析 |
| NGワード検出 | 改善が必要な表現を検出 |
| スキル評価 | 営業スキルの評価・可視化 |
| トーク改善 | 具体的な改善アドバイス |
| ベストプラクティス | 営業ノウハウの提供 |
| トップ営業比較 | 成績上位者との比較分析 |
| 音声文字起こし | 録音ファイルをテキスト化 |

## 4. 入力例

| 入力 | 期待される応答 |
|-----|--------------|
| `商談の録音を分析して`（+ 音声ファイル） | 総合分析結果 |
| `クロージングのコツを教えて` | ベストプラクティス |
| `私のスキル評価をして` | スキルレーダーチャート |
| `トップ営業と比較して` | ギャップ分析と改善点 |


## 8. スキル評価項目

| スキル | 説明 | 評価基準 |
|-------|------|---------|
| ヒアリング力 | 顧客課題を引き出す力 | 質問の質、傾聴姿勢 |
| 提案力 | 課題に対する解決策提案 | 論理性、説得力 |
| クロージング力 | 契約に導く力 | タイミング、テクニック |
| 商品知識 | 自社製品の理解度 | 正確性、深さ |
| コミュニケーション | 対人関係構築力 | 話し方、雰囲気作り |
| 課題発見力 | 潜在課題を見つける力 | 洞察力、仮説力 |
