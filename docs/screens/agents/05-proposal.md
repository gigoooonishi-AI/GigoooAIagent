## 3. 機能一覧

| 機能 | 説明 |
|-----|------|
| ストーリー生成 | 提案書のストーリーを自動生成 |
| 構成推薦 | 最適な提案書構成を推薦 |
| 見積自動生成 | ヒアリング内容から見積を生成 |
| 競合比較 | 競合との比較表を生成 |
| PDF出力 | 提案書をPDF形式で出力 |
| PPTX出力 | 提案書をPowerPoint形式で出力 |
| 過去案件参照 | 類似の受注案件から推薦 |

## 4. 入力例

| 入力 | 期待される応答 |
|-----|--------------|
| `株式会社XYZ向けにCRMの提案書を作成` | 提案書ストーリー全体 |
| `見積を自動生成して` | 見積明細と金額 |
| `競合A社との比較表を作成` | 比較表とトークポイント |
| `過去の類似案件から構成を推薦して` | 受注案件ベースの推薦 |

## 6. API連携

| エンドポイント | Method | 説明 |
|--------------|--------|------|
| `/api/chat` | POST | チャットAPI |
| `/api/proposals/ai/generate-story` | POST | ストーリー生成 |
| `/api/proposals/ai/recommend-structure` | POST | 構成推薦 |
| `/api/proposals/ai/generate-quote` | POST | 見積自動生成 |
| `/api/proposals/ai/competitor-comparison` | POST | 競合比較 |
| `/api/proposals/ai/recommend-from-history` | POST | 過去案件から推薦 |
| `/api/proposals/{id}/export/pdf` | GET | PDF出力 |
| `/api/proposals/{id}/export/pptx` | GET | PPTX出力 |

## 7. システムプロンプト

```
提案資料作成エージェントです。顧客ニーズに合わせた提案書を自動生成します。
```

## 8. 出力形式

### PDF出力
- A4サイズ
- 日本語フォント対応（MSゴシック）
- 見積表・グラフ含む

### PPTX出力
- 16:9 ワイドスクリーン
- スライド構成:
  1. タイトル
  2. 顧客概要
  3. 課題認識
  4. 提案内容
  5. 期待効果
  6. 見積
