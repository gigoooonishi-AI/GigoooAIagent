## 1. 概要

| 項目 | 内容 |
|-----|------|
| エージェントID | `progress` |
| 名前 | 進捗管理 |
| アイコン | 📈 |
| 説明 | 案件の進捗状況分析、ボトルネック特定、対策提案 |

## 3. 機能一覧

| 機能 | 説明 |
|-----|------|
| 進捗サマリー | パイプライン全体の状況 |
| ボトルネック分析 | 滞留ステージの特定 |
| 予測分析 | 売上予測・達成率 |
| 対策提案 | 改善アクションの提案 |
| トレンド分析 | 前月・前年比較 |

## 4. 入力例

| 入力 | 期待される応答 |
|-----|--------------|
| `今月の進捗状況を教えて` | パイプライン状況、主要指標 |
| `ボトルネックはどこ？` | 滞留ステージと原因分析 |
| `今月の売上予測は？` | 売上予測と達成確率 |
| `滞留している案件を教えて` | 14日以上進捗なしの案件一覧 |

## 8. パイプラインステージ

| ステージ | 説明 | 標準確度 |
|---------|------|---------|
| 初回商談 | 初回のヒアリング・商談 | 10% |
| 提案中 | 提案書を提出済み | 30% |
| 見積提出 | 見積書を提出済み | 50% |
| 最終交渉 | 条件交渉中 | 70% |
| 受注 | 契約完了 | 100% |
| 失注 | 案件終了（失注） | 0% |
