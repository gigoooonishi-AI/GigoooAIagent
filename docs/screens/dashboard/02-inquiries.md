## 3. コンポーネント詳細

### サマリーカード

| カード | 説明 | 計算方法 |
|-------|------|---------|
| 本日新規 | 本日受付の問い合わせ | created_at = TODAY |
| 未対応 | 未対応の問い合わせ | status = 'open' |
| 対応中 | 対応中の問い合わせ | status = 'in_progress' |
| 解決済 | 解決済みの問い合わせ | status = 'resolved' |
| SLA違反 | SLA超過の問い合わせ | is_sla_breached = true |

### チャネル別統計

| チャネル | アイコン |
|---------|---------|
| メール | 📧 |
| 電話 | 📞 |
| チャット | 💬 |
| Web | 🌐 |

### テーブルカラム

| カラム | 説明 |
|-------|------|
| ID | 問い合わせID |
| 件名 | 問い合わせ件名 |
| 顧客名 | 顧客の名前/会社名 |
| チャネル | 受付チャネル |
| ステータス | 対応状況 |
| SLA | SLA遵守状況 |

### ステータスアイコン

| ステータス | アイコン | 色 |
|-----------|---------|-----|
| 未対応 | 🔴 | 赤 |
| 対応中 | 🟡 | 黄 |
| 解決済 | 🟢 | 緑 |

### SLAアイコン

| 状態 | アイコン |
|-----|---------|
| SLA内 | ✅ |
| SLA違反 | ⚠️ |

## 5. API連携

| エンドポイント | Method | 説明 |
|--------------|--------|------|
| `/api/sales/inquiries` | GET | 問い合わせ一覧 |
| `/api/sales/inquiries` | POST | 問い合わせ作成 |
| `/api/sales/inquiries/{id}` | GET | 問い合わせ詳細 |
| `/api/sales/inquiries/{id}` | PUT | 問い合わせ更新 |
| `/api/sales/inquiries/{id}/responses` | GET | 対応履歴 |
| `/api/sales/inquiries/{id}/responses` | POST | 返信追加 |
| `/api/sales/inquiries/{id}/generate-response` | POST | AI回答生成 |
| `/api/sales/inquiries/stats` | GET | 統計情報 |
| `/api/sales/inquiries/channel-stats` | GET | チャネル別統計 |

## 6. データ構造

```typescript
interface Inquiry {
  id: number;
  subject: string;
  customer_name: string;
  customer_email: string;
  channel: 'email' | 'phone' | 'chat' | 'web';
  status: 'open' | 'in_progress' | 'resolved' | 'closed';
  priority: 'high' | 'medium' | 'low';
  content: string;
  created_at: string;
  sla_target_minutes: number;
  sla_deadline?: string;
  first_response_at?: string;
  response_time_minutes?: number;
  is_sla_breached: boolean;
  assigned_to?: number;
  category?: string;
}

interface InquiryResponse {
  id: number;
  inquiry_id: number;
  content: string;
  responded_by: number;
  created_at: string;
}
```
