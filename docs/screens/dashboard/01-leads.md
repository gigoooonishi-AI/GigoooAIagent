## 3. コンポーネント詳細

### サマリーカード

| カード | 説明 | 計算方法 |
|-------|------|---------|
| 総件数 | 全リード数 | COUNT(*) |
| アクティブ | 活動中リード | status NOT IN ('won', 'lost') |
| HOT | 高優先度 | temperature = 'hot' |
| WARM | 中優先度 | temperature = 'warm' |
| 期限切れ | 次アクション期限超過 | next_action_date < NOW() |

### フィルター

| フィルター | 選択肢 |
|-----------|-------|
| ステータス | 全て、新規、商談中、提案済、受注、失注 |
| 温度 | 全て、HOT、WARM、COLD |
| 業界 | 全て、製造業、IT、金融、その他 |
| 担当者 | 全て、{担当者リスト} |

### テーブルカラム

| カラム | 説明 | ソート |
|-------|------|-------|
| 会社名 | 会社名 | ○ |
| 担当者 | 担当営業 | ○ |
| 温度 | HOT/WARM/COLD | ○ |
| スコア | 優先度スコア（0-100） | ○ |
| 次アクション | 次の予定アクション | - |
| 操作 | 詳細、編集、削除 | - |

## 6. API連携

| エンドポイント | Method | 説明 |
|--------------|--------|------|
| `/api/sales/leads` | GET | リード一覧 |
| `/api/sales/leads` | POST | リード作成 |
| `/api/sales/leads/{id}` | GET | リード詳細 |
| `/api/sales/leads/{id}` | PUT | リード更新 |
| `/api/sales/leads/{id}` | DELETE | リード削除 |
| `/api/sales/leads/{id}/analyze` | POST | AI分析 |
| `/api/sales/leads/{id}/activities` | GET | 活動履歴 |
| `/api/sales/leads/{id}/activities` | POST | 活動追加 |
| `/api/sales/leads/stats` | GET | 統計情報 |

## 7. データ構造

```typescript
interface Lead {
  id: number;
  company_name: string;
  contact_name: string;
  contact_email: string;
  contact_phone?: string;
  status: 'new' | 'contacting' | 'negotiating' | 'proposal' | 'won' | 'lost';
  priority: 'high' | 'medium' | 'low';
  score: number;
  temperature: 'hot' | 'warm' | 'cold';
  estimated_value: number;
  next_action: string;
  next_action_date: string;
  last_contact_date: string;
  industry: string;
  company_size?: string;
  source?: string;
  notes?: string;
  assigned_to?: number;
}

interface LeadActivity {
  id: number;
  lead_id: number;
  type: 'call' | 'email' | 'meeting' | 'note';
  subject: string;
  description?: string;
  outcome?: string;
  activity_date: string;
}
```
