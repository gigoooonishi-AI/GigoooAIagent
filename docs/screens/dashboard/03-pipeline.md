## 3. コンポーネント詳細

### パイプライン概要

| 指標 | 説明 |
|-----|------|
| 総パイプライン | 全商談の合計金額 |
| 加重平均 | 金額 × 確度の合計 |
| 受注率 | 受注件数 / 完了件数 |
| 平均リードタイム | 作成〜受注までの平均日数 |

### 売上予測カード

| 期間 | 表示内容 |
|-----|---------|
| 今月 | 今月クローズ予定の予測金額 |
| 今四半期 | 今四半期のクローズ予測 |
| 今期 | 今期全体の予測 |

**内訳:**
- 高確度（70%以上）
- 中確度（40-69%）
- 低確度（40%未満）

### カンバンビュー

```
┌──────────┐
│ ステージ  │
│ 件数     │
│ 金額     │
├──────────┤
│┌────────┐│
││ 会社名  ││

```

- カードはドラッグ&ドロップでステージ移動
- カードクリックで詳細モーダル

### 滞留アラート

| 重要度 | 条件 | アイコン |
|-------|------|---------|
| 高 | 21日以上滞留 | 🔴 |
| 中 | 14-20日滞留 | 🟡 |
| 低 | 7-13日滞留 | 🟢 |

## 5. API連携

| エンドポイント | Method | 説明 |
|--------------|--------|------|
| `/api/sales/pipeline/deals` | GET | 商談一覧 |
| `/api/sales/pipeline/deals` | POST | 商談作成 |
| `/api/sales/pipeline/deals/{id}` | GET | 商談詳細 |
| `/api/sales/pipeline/deals/{id}` | PUT | 商談更新 |
| `/api/sales/pipeline/deals/{id}` | DELETE | 商談削除 |
| `/api/sales/pipeline/analytics` | GET | パイプライン分析 |
| `/api/sales/pipeline/forecast` | GET | 売上予測 |
| `/api/sales/pipeline/stalled-alerts` | GET | 滞留アラート |
| `/api/sales/pipeline/by-owner` | GET | 担当者別 |

## 6. データ構造

```typescript
interface Deal {
  id: number;
  title: string;
  stage: 'first_meeting' | 'proposal' | 'quote' | 'negotiation' | 'closed_won' | 'closed_lost';
  amount: number;
  probability: number;
  expected_close_date: string;
  lead_id: number;
  owner_id: number;
  days_stalled?: number;
  created_at: string;
  updated_at: string;
}

interface PipelineMetrics {
  stage_metrics: Record<string, {
    count: number;
    total_amount: number;
    weighted_amount: number;
  }>;
  win_rate: number;
  total_pipeline_value: number;
}

interface ForecastData {
  current_month: ForecastPeriod;
  current_quarter: ForecastPeriod;
  total_pipeline: ForecastPeriod;
}

interface ForecastPeriod {
  period: string;
  total_amount: number;
  weighted_amount: number;
  high_probability: number;
  mid_probability: number;
  low_probability: number;
  deal_count: number;
}
```

## 7. ステージ定義

| ステージ | 説明 | 標準確度 |
|---------|------|---------|
| first_meeting | 初回商談 | 10% |
| proposal | 提案中 | 30% |
| quote | 見積提出 | 50% |
| negotiation | 最終交渉 | 70% |
| closed_won | 受注 | 100% |
| closed_lost | 失注 | 0% |
