│                                                                         │

│                                                                         │
│  分析結果は以下の通りです：                                             │
│                                                                         │
│  | 項目     | 値        |                                               │

| system | ⚙️ | `#1f1f2e` | システムメッセージ |
| error | ❌ | `#2a1a1a` | エラーメッセージ |

## 2. 入力コンポーネント

### チャット入力エリア

```
┌─────────────────────────────────────────────────────────────────────────┐
│ ┌─────────────────────────────────────────────────────────────────────┐ │
│ │                                                                     │ │
│ │  メッセージを入力...                                               │ │
│ │                                                                     │ │
│ └─────────────────────────────────────────────────────────────────────┘ │
│                                                                         │
│  [📎 ファイル]  [🎤 音声]                              [📤 送信]        │
└─────────────────────────────────────────────────────────────────────────┘
```

### 入力プロパティ

| プロパティ | 型 | デフォルト | 説明 |
|-----------|------|----------|------|
| placeholder | string | "メッセージを入力..." | プレースホルダー |
| maxLength | number | 10000 | 最大文字数 |
| disabled | boolean | false | 無効状態 |
| showFileUpload | boolean | true | ファイルアップロード表示 |
| showVoiceInput | boolean | false | 音声入力表示 |

### ファイルアップロード

| ファイルタイプ | 拡張子 | 最大サイズ |
|--------------|--------|----------|
| 文書 | .pdf, .docx, .xlsx | 10MB |
| 画像 | .jpg, .png, .gif | 5MB |
| 音声 | .mp3, .m4a, .wav | 50MB |
| テキスト | .txt, .csv, .md | 5MB |

## 4. モーダルコンポーネント

### 基本構造

```
┌─────────────────────────────────────────────────────────────────┐
│  モーダルタイトル                                          [×]  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  コンテンツエリア                                               │
│                                                                 │
│                                                                 │
│                                                                 │
├─────────────────────────────────────────────────────────────────┤
│                              [キャンセル] [確定]                │
└─────────────────────────────────────────────────────────────────┘
```

### モーダルサイズ

| サイズ | 幅 | 用途 |
|-------|-----|------|
| small | 400px | 確認ダイアログ |
| medium | 600px | フォーム |
| large | 800px | 詳細表示 |
| full | 90vw | ダッシュボード |

### モーダルプロパティ

| プロパティ | 型 | 説明 |
|-----------|------|------|
| isOpen | boolean | 表示状態 |
| onClose | function | 閉じる時のコールバック |
| title | string | タイトル |
| size | string | サイズ |
| showCloseButton | boolean | 閉じるボタン表示 |
| closeOnOverlay | boolean | オーバーレイクリックで閉じる |

## 7. テーブルコンポーネント

### 基本テーブル

```
┌─────────────────────────────────────────────────────────────────┐
│ ID    │ 名前        │ ステータス │ 更新日     │ 操作           │
├─────────────────────────────────────────────────────────────────┤

│                           [<] 1 2 3 ... 10 [>]                  │
└─────────────────────────────────────────────────────────────────┘

### テーブル機能

| 機能 | 説明 |
|-----|------|

| 行選択 | チェックボックスによる複数選択 |
