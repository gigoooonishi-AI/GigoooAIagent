## 1. システム概要

### 1.1 アプリケーション概要
営業活動を支援するAIエージェントシステム。7つの専門AIエージェントと営業ダッシュボードで構成。

### 1.2 技術スタック
| 層 | 技術 |
|---|------|
| フロントエンド | React + TypeScript + Vite |
| バックエンド | FastAPI (Python) |
| データベース | SQLite (SQLAlchemy ORM) |
| AI | OpenAI GPT-4 |
| 通信 | REST API + WebSocket (ストリーミング) |
